# MeetAware – Intelligent Meeting Assistant (Frontend)

MeetAware is a web-based intelligent meeting assistant designed to help users manage meetings, review meeting summaries, and organize important decisions and action items through a user-friendly dashboard.

## Features

* **User Authentication:** Register and log in to access the application.
* **Dashboard:** Access meeting-related information through a centralized interface.
* **Meeting Management:** View and manage meeting information.
* **Meeting Summaries:** Review AI-generated meeting summaries when available.
* **Action Items:** Organize important tasks and follow-up activities from meetings.
* **Responsive UI:** Clean and user-friendly interface for a better user experience.
* **Backend Integration:** Communicate with backend APIs for authentication and meeting data.

## Tech Stack

* **Frontend:** React.js
* **Build Tool:** Vite
* **Styling:** Tailwind CSS
* **Language:** JavaScript
* **API Integration:** Fetch / Axios (as implemented in the project)


## Backend

The frontend communicates with the MeetAware backend for authentication, meeting information, and other supported features.

**Backend technologies:** Node.js, Express.js, MongoDB, JWT authentication.
